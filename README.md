## Install

1. Install [Millennium](https://steambrew.app)
2. Put the `MontBlack` folder in `Steam/millennium/themes/`
3. Open Steam → Millennium → Themes
4. Select **Mont Black**, turn on CSS + JS injection, reload Steam
